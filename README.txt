Proyecto integrado de verificación académica.

Incluye:
- Flujo principal de consulta.
- Registro de graduados.
- Generación automática de código de verificación.
- Generación de código QR.
- Página de verificación al escanear el QR.
- Lista de registros.
- SQLite y configuración para Render.

Rutas principales:
/           Consulta
/registro   Registro de graduados
/registro/lista  Lista de registros

Instalación:
python -m pip install -r requirements.txt
python app.py
